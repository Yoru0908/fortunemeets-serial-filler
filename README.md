# シリアル入力ヘルパー（forTUNE Serial Filler）

forTUNE meets のシリアルナンバー入力を楽にする Chrome 拡張機能です。30 枚、50 枚、それ以上の券も、写真を Gemini に読み取らせて貼り付けるだけで番号リストになり、入力欄に 10 件ずつ入れられます。

- 全角→半角・記号や空白の除去・13 桁チェック・重複スキップを自動で処理
- 10 件ずつのバッチで入力し、成功／失敗を記録。失敗分だけ再入力
- 番号はパソコン内（拡張機能のローカル保存）だけ。ID・パスワードは扱いません
- 日本語 / 中文 / English 切り替え対応

> 非公式ツールです。運営各社とは一切関係ありません。ご利用は自己責任でお願いします。

*The extension UI is available in Japanese, Chinese and English; this README is in Japanese. 界面支持日语／中文／英语，本说明为日语。*

## ダウンロード

[Releases](https://github.com/Yoru0908/fortunemeets-serial-filler/releases/latest) から最新版の ZIP（`serial-filler-v<バージョン>.zip`）をダウンロードしてください。

パソコン版 Chrome / Edge 専用です。スマートフォンでは使えません（写真の撮影と Gemini はスマホで OK）。

## インストール方法

1. ダウンロードした ZIP を解凍します（フォルダは削除・移動しないでください）。
2. Chrome のアドレス欄に `chrome://extensions` を入力して開きます（Edge は `edge://extensions`）。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」から、解凍したフォルダ（`manifest.json` があるフォルダ）を選びます。
5. 開いている forTUNE のページを F5 で再読み込みします。

## 使い方：たくさんの券をまとめて登録する

### 1. 券を撮影する

- 券を机に並べ、シリアルナンバーの部分がはっきり読めるように撮ります。1 枚の写真に 50 枚くらいまで並べても読み取れました。番号が小さすぎて読めない場合は、枚数を減らして撮り直してください。
- 真上から、明るい場所で。光の反射・ピンぼけ・指やほかの券で番号が隠れていないか確認してください。
- 身分証・住所など、関係のないものは写さないでください。

### 2. Gemini に読み取らせる

1. Gemini（アプリまたは `gemini.google.com`）で新しいチャットを開きます。
2. 下の[プロンプト](#gemini-に送るプロンプト)をコピーして送ります。
3. 撮った写真を送ります。写真が何枚もあるときは数枚ずつ送れば、そのたびに番号の一覧（`["XXXXXXXXXXXXX", …]` の形）が返ってきます。
4. 返ってきた一覧をコピーします（スマホで撮った場合は、パソコンの Gemini で同じチャットを開くとコピーしやすいです）。

### 3. 拡張機能に貼り付ける

1. forTUNE meets のシリアル入力ページを開き、右下の「Serial」ボタン（またはツールバーの拡張機能アイコン）を押します。
2. Gemini の結果をそのまま貼り付けて「リストに追加」。何回貼っても、同じ番号は自動でスキップされます。
3. パネルの「合計」と手元の券の枚数が合っているか確認します。足りない分は、その券を見ながら「番号を手入力」で追加してください（Gemini は読めない番号を出さない設定です）。

### 4. 10 件ずつ登録する

1. 「次の10件を入力」→ 内容を確認して、サイトの送信ボタンを自分で押します。
2. 登録できたら「このバッチは成功」、エラーなら「このバッチは失敗」。これを繰り返します（50 枚なら 5 回）。
3. 失敗したバッチは、読み間違い（0 と O、1 と I など）がないか券と見比べてから「失敗分を再入力」。

入力したけど送信しなかった場合は「確認待ちを戻す」で未使用に戻せます。拡張機能アイコン →「書き出し」で、番号リストを JSON でバックアップできます。

Gemini を使わずに、OCR の結果や手で打った番号を貼り付けても同じように使えます。

## Gemini に送るプロンプト

```text
あなたは forTUNE meets のシリアルナンバー抽出係です。これから送る写真（シリアルナンバーが印字された券・カードを撮影したもの）から本物のシリアルナンバーだけを読み取り、Chrome 拡張機能にそのまま貼り付けられる形で出力してください。

【出力形式】
必ず JSON 配列ひとつだけを出力すること。
配列の各要素は、整形済みの 13 文字の英大文字・数字の文字列（^[A-Z0-9]{13}$）とする。
Markdown、説明文、オブジェクト、コードブロックは出力しない。
見つからない場合は [] を出力する。
写真を追加で送った場合は、その写真の分だけを同じルールで出力する。

【本物のシリアルの判定ルール】
1. 整形後に必ずちょうど 13 文字で、A-Z と 0-9 だけで構成されていること。
2. シリアルは空白・改行・ハイフンで区切られて印字・認識されることがある。「シリアルナンバー」「シリアル番号」「Serial No.」などの欄の近くで、明らかにひと続きの番号である場合だけ連結してよい。
3. 英語のタイトル、エラーメッセージ、氏名、身分証の項目、URL、イベント名、曲名、説明文から 13 文字を組み立てない。
4. 読める英単語・項目名・人名・身分証の語句・エラー語になる 13 文字は、通常シリアルではない。
5. 判読できない文字がある番号は推測・補完・創作せず、出力に含めない。迷ったら含めない。
6. 同じ番号が何度も写っていても 1 回だけ出力する。

【正しい例】
写真の文字: シリアルナンバー Z5HV6BJK6F2WT
出力: ["Z5HV6BJK6F2WT"]

写真の文字: Serial No. YHJW NQAU VZPWT
出力: ["YHJWNQAUVZPWT"]

写真の文字: シリアル番号 ABCD-1234-EFGH5
出力: ["ABCD1234EFGH5"]

写真の文字: 1. Z5HV6BJK6F2WT  2. YHJWNQAUVZPWT
出力: ["Z5HV6BJK6F2WT","YHJWNQAUVZPWT"]

【誤りの例】
写真の文字: 櫻坂46 15th Double A-side Single
出力: []
理由: イベント名をつなげて 4615THDOUBLEA にしてはいけない。

写真の文字: Upstream error
出力: []
理由: エラーメッセージであり、シリアルではない。文字数が 13 に近くても抽出しない。

写真の文字: RESIDENCE CARD / NAME YAMADA TARO / NATIONALITY JAPAN
出力: []
理由: 身分証の項目や氏名はシリアルではない。RESIDENCECARD や NAMEYAMADATARO を抽出しない。

写真の文字: https://example.com/ABC1234567890/path
出力: []
理由: URL のパスやパラメータはシリアルではない。

写真の文字: Lonesome rabbit What's KAZOKU?
出力: []
理由: 曲名・タイトル・普通の英文はシリアルではない。

これから写真を送ります。
```

※ Gemini・ChatGPT・Claude などの AI による読み取りは、間違い（読み落とし・誤読）がないことを保証できません。必ず手元の券と照合してください。読み取り結果やツールの利用によって生じたトラブル・損失は、ご自身の責任でお願いします。

## 注意

- 写真とシリアルナンバーは Google（Gemini）に送信されます。気になる方は手入力をお使いください。
- 「全自動登録」は入力・送信・続けて登録を自動で繰り返します。1 回でも失敗したら（エラー表示・完了ページに進まない・入力欄が足りないなど）、そのバッチを失敗にしてすぐ停止し、自動で再試行はしません。失敗分は券と見比べてから手動でやり直してください。サイト側に自動操作と判断され、アカウントが制限される可能性があります。使うかどうかはご自身で判断してください（不安な方は半自動をおすすめします）。
- 番号を入力しただけでは登録完了ではないので、必ずサイトの表示で確認してください。
- 「拡張機能が更新されました」と出たら、forTUNE のページを F5 で再読み込みしてください。

## 開発者向け

ビルド不要の Manifest V3 拡張機能です。このリポジトリをクローンして、フォルダをそのまま「パッケージ化されていない拡張機能を読み込む」で読み込めます。

| ファイル | 役割 |
|---|---|
| `manifest.json` | MV3 設定（権限は `activeTab` / `scripting` / `storage` のみ） |
| `i18n.js` | ja / zh / en の全 UI 文言（`messages.ja / zh / en`）。言語を足すときは同じキーの辞書と `LANGS` を追加 |
| `serial-core.js` | 13 桁英数字の整形（全角→半角・大文字化・A-Z/0-9 以外の除去）、番号プールの集計と重複スキップ |
| `page-dom.js` | ページの入力欄の検出、入力、ボタンの特定 |
| `content.js` | ページ内の `Serial` パネルと全自動登録の状態管理 |
| `popup.html` / `popup.js` | ツールバーのポップアップ |
| `content.css` / `popup.css` | スタイル |

- 対象ページ：`ticket.fortunemeets.app`、`*.fortunemeets.app`、`fortunemusic.jp`、`*.fortunemusic.jp`、`fortunemusic.app`、`*.fortunemusic.app`
- 番号の状態：`unused` / `pending` / `success` / `failed` / `duplicate` / `skipped`。`success` になるのは、送信後に自分で「このバッチは成功」を押したときだけです。
- 保存先は `chrome.storage.local` のみ。外部への通信はありません。
